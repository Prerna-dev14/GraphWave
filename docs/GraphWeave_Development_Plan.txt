Risk register

LLM extraction can create false relationships; preserve provenance, confidence, validation, and evaluation.

Entity resolution can merge distinct entities; ambiguous matches should remain separate or require review.

Graph expansion can explode in size; enforce traversal depth, fan-out, timeouts, and query budgets.

Graph answers can sound certain despite weak paths; require evidence-backed citations and explicit uncertainty.

Release checklist

Clean clone and setup verified from README.

No committed credentials, local database files, or user data.

Migrations, seed script, lint, type checks, tests, and production frontend build pass.

Critical security boundaries have explicit tests.

Evaluation report includes dataset description, method, baseline, results, limitations, and reproducibility details.

Demo does not expose real secrets or sensitive documents.

Resume claims are updated only after measured results exist; never invent percentages or claim unverified improvements.
